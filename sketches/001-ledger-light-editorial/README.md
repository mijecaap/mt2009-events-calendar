## Variant 001 — Ledger (light editorial)

**Stance:** calm, precise, paper-like. The schedule reads like an agenda in a well-set print magazine.

**Key choices**
- Layout: narrow month rail + wide agenda list (agenda-first, not grid-first)
- Typography: Newsreader serif for the day/month headings, Inter for UI, JetBrains Mono for times
- Color: warm off-white canvas (#f7f6f1), near-black ink, a single terracotta accent for "live"; event type shown as a 3px color bar
- Interaction: prev/next month, tap a day, Lima↔Servidor toggle, live marker

**Trade-offs**
- Strong at: readability, low cognitive load, works great on mobile, feels trustworthy
- Weak at: less "at a glance" density; not gamer-flavored

**Best for**
- Someone who opens the page to answer "what's on today, in order".
