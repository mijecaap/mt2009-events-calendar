## Variant 002 — Nightshift (dark monitor)

**Stance:** a precise dark dashboard. The page answers "what is live right now and what's next" before you read a single row.

**Key choices**
- Layout: full-width "Ahora / Siguiente" band, then a day timeline (main) + a compact month/legend rail
- Typography: Inter with OpenType `cv01/ss03`, JetBrains Mono for all times; weight 510 as the workhorse
- Color: near-black canvas (#08090a), hairline translucent borders, restrained gold accent, green reserved for LIVE
- Interaction: live pulsing markers, countdown to next event, month nav, tz toggle

**Trade-offs**
- Strong at: glanceability, "is anything on now?" in <1s, gamer-friendly, low eye-strain at night
- Weak at: heavier reading than the light variant; more visual chrome

**Best for**
- Someone who checks "is there an event live / when's the next one" several times a day.
