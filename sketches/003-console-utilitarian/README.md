## Variant 003 — Console (utilitarian dense)

**Stance:** a tool, not a page. A compact month selector next to a dense, aligned data table of the day.

**Key choices**
- Layout: split-pane — month grid rail (left) + day "table" with columns Hora / Evento / Duración / Intensidad (right)
- Typography: JetBrains Mono for times, durations and numbers; Inter for names
- Color: cool light-gray chrome (#eceef2), white panels, colored type swatches; no accent color beyond the data itself
- Interaction: row hover, month nav, day select, tz toggle, live marker

**Trade-offs**
- Strong at: maximum information per screen, scannable columns, feels precise/expert on desktop
- Weak at: busier; the table needs horizontal breathing room and is less inviting on a phone

**Best for**
- Desktop power use — comparing durations and intensities across a day at a glance.
